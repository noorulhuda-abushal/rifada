# رِفادة | Rifada

منصة تساعد حملات الحج على إيجاد فنادق مناسبة في مكة المكرمة: الأسعار، والغرف الشاغرة، والمسافة من المسجد الحرام، وتوزيع الرجال والنساء على الغرف تلقائياً.

> نسخة مبدئية للعرض — جميع الفنادق والأسعار تجريبية.

## الخصائص
- البحث بعدد الرجال والنساء وتواريخ الإقامة (تُعرض بالتاريخ الهجري)
- خريطة حقيقية تبيّن الفنادق حول الحرم ووقت المشي إليه
- تصفية حسب وقت المشي، ونوع الغرفة، وفصل الرجال عن النساء، وتهيئة كبار السن
- اقتراح توزيع الأفراد على الغرف وحساب السعر الإجمالي
- حجز مبدئي برقم حجز
- لوحة للفندق: تعديل الأسعار والشاغر، وقبول طلبات الحجز أو رفضها
- لغتان: العربية والإنجليزية (الأوردو والإندونيسية قيد الإعداد)
- الوضع الليلي

## طريقة التشغيل
1. افتح مجلد `rifada-site` في Visual Studio Code.
2. ثبّت إضافة **Live Server**.
3. اضغط بالزر الأيمن على `index.html` ثم اختر **Open with Live Server**.

الخريطة والخطوط تحتاج اتصالاً بالإنترنت.
